# Code of Conduct

## Our commitment

We want this project to be a respectful, inclusive, and technically rigorous space for everyone.

Participants are expected to:

- Communicate respectfully and constructively.
- Focus on technical issues, data, and reproducible results.
- Assume good intent while giving direct, actionable feedback.
- Avoid harassment, personal attacks, discrimination, and intimidation.

## Scope

This applies to all project spaces, including issues, pull requests, discussions, and related communication channels.

## Enforcement

Project maintainers may remove, edit, or reject comments and contributions that violate this Code of Conduct.
Repeated or severe violations may result in temporary or permanent bans from project participation.

## Reporting

If you experience or witness unacceptable behavior, report it privately to the repository maintainer through GitHub.
Reports will be reviewed promptly and handled as confidentially as possible.
